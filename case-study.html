How I built the Digital Shelf: Availability report

The problem it solves, the data model behind it, the measure that drives the period buttons, and what changed for the client.

The problem

Brands that sell through several delivery and marketplace platforms need to know where their products are actually in stock. A product can look healthy overall and still be missing in specific stores on one platform.

This report tracks availability by brand, product, platform and store. One click compares the last three months, the last six months, last year, month to date and year to date, and every visual on the page follows the choice.

The data model

One fact table of availability checks sits in the middle. Brand, SKU, category, date and platform each get their own dimension table, stores hang off their platform, and categories also feed the SKU table. The period buttons, comparison dates and measures live in disconnected tables, so they filter through DAX instead of relationships.

The measure behind the period buttons

Every visual uses one measure, Total Availability (Dynamic). It reads the period picked on the PeriodSelector buttons, works out a start and an end date, and averages availability only inside that window. Last Year is pinned to the 2025 calendar year; every other period runs up to today.

Total Availability (Dynamic) =
VAR SelectedPeriod = SELECTEDVALUE(PeriodSelector[Period], "YTD")
VAR TodayDate = TODAY()

-- 1. Determine Start Date
VAR StartDate =
    SWITCH(
        TRUE(),
        SelectedPeriod = "Last 3 Months", EDATE(TodayDate, -3),
        SelectedPeriod = "Last 6 Months", EDATE(TodayDate, -6),
        SelectedPeriod = "Last Year", DATE(2025, 1, 1),    -- Hardcoded Start for 2025
        SelectedPeriod = "MTD", DATE(YEAR(TodayDate), MONTH(TodayDate), 1),
        SelectedPeriod = "YTD", DATE(YEAR(TodayDate), 1, 1),
        DATE(2000, 1, 1) -- Default
    )

-- 2. Determine End Date (New Logic)
VAR EndDate =
    IF(
        SelectedPeriod = "Last Year",
        DATE(2025, 12, 31),  -- Hardcoded End for 2025
        TodayDate             -- For everything else, stop at Today
    )

RETURN
CALCULATE(
    AVERAGE('Availability'[Availability]),
    FILTER(
        'Availability',
        'Availability'[Date] >= StartDate &&
        'Availability'[Date] <= EndDate  -- Updated to use the variable
    )
)
